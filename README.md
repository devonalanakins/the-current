# The Current

**The Current** is a proposed narrative-first briefing experience engine, built as an independent Mizvo client project.

**Current status:** Design V0.3. No production application, hosted platform, public launch, real client contract, or verified end-to-end application is claimed.

## User experiences

- **Participant:** Open one accessible, spoiler-free invitation with a captioned teaser.
- **Facilitator:** Run a guided, 30-minute conversation and deliberately reveal a fictional scene.
- **Investigator:** Review only approved, released fictional evidence.
- **Producer:** Prepare campaign episodes, original media, previews, versions and approvals.

Private workplace-culture conversations are separate from fictional story content. V1 does not store or assess real employee feedback, clinical information, patient data, or calls.

## Engineering approach

Start with a portable, self-hostable original demo using synthetic content. Verify server-side audience permissions, explicit version-bound approvals, accessible mobile runner and carefully gated fictional evidence release. Keep any client-specific or third-party copyrighted media in separately authorized private storage. Do not implement automated messages or real-employee feedback tracking by default.
